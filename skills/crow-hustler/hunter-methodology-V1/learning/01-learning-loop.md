# Learning Loop

## The 70/20/10 Model

- **70% live hunting** (apply)
- **20% reading write-ups** (consume)
- **10% theory / setup** (background)

If >50% reading and <30% hunting → you will burn out without progress.

## The 5 Phases

### 1 — Define + Form Questions
- What is it? Why dangerous? Where to look? How it works?
- Form 5 explicit questions first.

### 2 — Search
PortSwigger → Hacktivity → GitHub write-ups → OWASP → YouTube

### 3 — Read 5 Disclosed Reports
Theory ≠ reality. Real bugs chain two things.

### 4 — Test-Bed
Docker → recreate vulnerable pattern → trigger it → break protections.

### 5 — Rephrase + Apply
Explain in your own words. Apply next live session. Without application, learning evaporates in days.

## Mastery Self-Check

1. Can recall it (name, payload, impact)
2. Can explain it (paragraph in own words)
3. Can test it on a live target
4. Can recognize it elsewhere (5 disclosed reports)
5. Can judge impact (P1-P5 from memory)
6. Can produce from it (tool, write-up, or test case)

Don't move to next class until level 5.
