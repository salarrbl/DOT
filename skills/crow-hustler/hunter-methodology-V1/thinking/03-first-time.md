# First Time Seeing Something

When you encounter a bug class or technology you don't understand:

## The 5-Phase Learning Loop

### Phase 1 — Define + Form Questions
- What is it? (one sentence)
- Why is it dangerous? (impact)
- When does it occur? (where to look)
- How does it work? (mechanics)
- **Form 5 questions before searching**

### Phase 2 — Search (in priority)
1. PortSwigger Web Security Academy — best free + labs
2. HackerOne Hacktivity / Bugcrowd disclosed — real reports
3. GitHub write-ups, infosecwriteups.com
4. OWASP — theory
5. AI assistants — verify claims
6. YouTube: NahamSec, STÖK, InsiderPhD, LiveOverflow

### Phase 3 — Read 5 Disclosed Reports
Theory ≠ reality. Real bugs chain things.

### Phase 4 — Test-Bed (critical)
- Docker image for the technology
- Recreate the vulnerable pattern
- Trigger the bug yourself
- Break protections → unbreak them → learn the flow

### Phase 5 — Rephrase + Apply
- Write a 1-paragraph explanation in your own words
- If you can't explain it simply, you don't understand it
- Apply on your next live session
