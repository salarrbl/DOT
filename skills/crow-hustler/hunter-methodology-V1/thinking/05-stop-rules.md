# Self-STOP Rules

Hard triggers. Burnout + wasted time = nothing good.

| Trigger | Action |
|---------|--------|
| **Saturated target**: 5 deep passes, no new finding | Switch target |
| **Repeat-Duplicate**: 3rd duplicate in 30 days | Stop front-end. Move to logic/auth. |
| **Time Trap**: >2h with zero progress | Unblock-loop or stop, save notes, sleep |
| **Tool Trap**: tool making you dumber | Stop tool. Manual only for 24h. |
| **Bias Trigger**: writing "Reflected XSS" out of habit | Switch class. Stop submitting RXSS for 60 days. |
| **Anger Spike**: "I hate this program" | CLOSE the laptop. 24h break. |
| **Streak crash**: high → no progress → frustration | Read burnout protocol. Don't double down. |

## Re-validate After 24h

- Are trigger conditions still present?
- Have I recovered focus?
- Is the task different from outcome expectation?

If outcome expectation is the problem and the task is correct → reset expectation, not task.
