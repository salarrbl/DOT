## Post-Hunt Checklist

### Vault Updates
□ Did I discover a new technology?
□ Did I discover a new attack surface?
□ Did I discover a new framework?
□ Did I discover a new bypass?
□ Did I create a reusable payload?
□ Did I improve a checklist?
□ Did I improve a template?
□ Did I learn something worth documenting?

### Human Learning (Teach-Back) — NON-NEGOTIABLE
□ Did the agent produce a teach-back? (REQUIRED — `teach-back/YYYY-MM-DD-session.md`)
□ Did I READ the teach-back? (REQUIRED — do it NOW, not later)
□ Did I understand the ONE Thing I can use tomorrow?
□ Did I complete the "Your Turn" task? (proves I can do it without the agent)
□ Did I mark the confirmation checkboxes?

### Reflection
□ Did I waste time? Why?
□ How can future me avoid that?
□ What can I do TODAY that I couldn't do yesterday?
□ Did the agent learn something that I DIDN'T learn? (If yes — re-read the teach-back NOW)
