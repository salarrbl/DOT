# Teach-Back Vault: The Bridge From Agent to Human

The agent learns. Now you learn too. Not later. Not "I'll read the files someday." NOW. In 5-10 minutes. After every session.

## The Problem

```
Before:
  Agent works → Agent writes to vault → Human never reads → Vault gets smarter
  Agent continues → Agent references vault → Agent gets smarter
  Human is the same as yesterday → Gap widens → Human becomes observer, not doer

You become the person who "has an AI" — not the person who IS the hacker.
```

## The Solution

```
After (teach-back):
  Agent works → Agent writes teach-back (5 min to read) → Human READS it NOW
  Human absorbs → Human applies on next hunt → Human grows alongside agent

You don't watch the AI hack. You LEARN from it, then you hack better yourself.
```

## How Teach-Back Works

After every hunting, learning, or research session, the agent produces a single file:

```
teach-back/YYYY-MM-DD-session-name.md
```

You read it **immediately** (not tomorrow, not later — NOW, while the context is fresh).

The file is SHORT. Maximum 5-10 minutes to read. Written for HUMANS, not for the vault.

## The Flow

```
HUNT SESSION ENDS
    ↓
Agent writes vault updates (methodology, payloads, findings)
    ↓
Agent writes teach-back (human-readable summary)
    ↓
HUMAN READS TEACH-BACK (5-10 min, now)
    ↓
Human marks: [x] Read, [x] Understood, [x] Will apply
    ↓
NEXT HUNT: Human applies what they learned
```

## Teach-Back File Structure

Every teach-back has:

1. **What We Did** (2-3 lines — the session summary)
2. **What I Learned** (the agent's new knowledge, written TO the human)
3. **What Changed in the Vault** (what files were created/modified — so you know where to look)
4. **One Thing You Can Use Tomorrow** (the single most actionable insight)
5. **New Technique You Can Execute Yourself** (so YOU learn to do it, not just the agent)
6. **Your Turn** (a specific task the human should try WITHOUT the agent's help)

##  Human Review Cadence

| When | What |
|------|------|
| After every hunt | Read the teach-back (5-10 min) |
| End of day | Skim all today's teach-backs (5 min) |
| End of week | Review all teach-backs, pick top 3 to practice (20 min) |
| End of month | Review monthly learnings, update personal skill tracker (30 min) |
