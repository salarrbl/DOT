# Daily Rhythm

## Time Blocks

| Block | Duration | Activity |
|-------|----------|---------|
| Block 1 | 2-3h | Deep hunting (one target, one feature) |
| Block 2 | 1-2h | Learning (write-up, course, technique) |
| Block 3 | 1-2h | Tooling/docs (Cexss, notes, templates) |
| **Total** | **5-7h** | Focused |

Fixed blocks, variable intensity. No "8-14 hour ranges" — psychologically destructive.

## The 6-Item Daily Checklist

- [ ] One hypothesis tested on chosen target
- [ ] ≥1 hour focused on chosen target
- [ ] 30 min learning (write-up / video / doc)
- [ ] 20 min English input
- [ ] Toothbrush
- [ ] $ earned this month: ___
