# Anti-Burnout Protocol

## 8 Rules

1. **Burnout comes from high-effort + delayed reward.** Manufacture short feedback cycles daily: one concrete output (a note, a script, a payload list).

2. **No output = burnout.** Effort alone is not enough.

3. **Automation is non-optional.** Repeat something twice → script on third time.

4. **Learning without hunting = slow poison.** Ratio: 60% hunting / 25% learning / 15% documentation.

5. **Community, filtered.** If community makes you compare → leave. If it makes you build → stay.

6. **Self-care.** Physical training, sleep discipline, non-tech mental escape.

7. **Wins redefined.** Better recon coverage, faster hypothesis testing, cleaner notes — money is a lagging indicator.

8. **Golden rule: Never quit on a bad day. Never overwork on a good day.**

## 90-Day Challenge

Cash targets: $100 → $200 → $500 → $1000 → $1500 → $2000 → $2500
Hour targets: 800h → 1044h → 1200h
Report targets: 20 → 50 → 70 → 100

If by mid-point no $ → pivot. If by mid-point no reports → methodology issue.
