# Human Review — Absorb What the Agent Learned

> The agent learns every session. If you don't absorb it, only the agent grows. This time block is non-negotiable.

## Daily Review (5-10 minutes)

**When:** End of day, before closing the laptop.

```
1. Open teach-back/ directory
2. Read today's teach-back(s)
3. Check the [x] confirmation boxes
4. Ask yourself: "Do I actually understand the ONE thing?"
5. If yes → close. If no → ask the agent to re-explain.
```

## Weekly Review (20-30 minutes)

**When:** Saturday or Friday afternoon. Low-pressure time.

```
1. Open all teach-backs from this week
2. Re-read only the "ONE Thing" and "New Technique" sections
3. Pick TOP 3 things you want to practice
4. For each: try it on a test target (not a real bounty program)
5. Write one sentence about each in your weekly note
6. Delete or archive teach-backs older than 2 weeks (you've absorbed them by now)
```

## Monthly Review (30-45 minutes)

**When:** Last day of the month.

```
1. Review all weekly reviews
2. Update your personal skills tracker
3. Write: "This month I learned..."
4. Identify: skills you can now do without the agent
5. Identify: skills you still need the agent for (target these next month)
6. Archive old teach-backs (move to teach-back/archive/)
```

## The Golden Rule of Human Review

> **If you skip reviews for 3 days, you are falling behind your own agent.** The gap doesn't close itself. Reviews are how you close it.

## What Happens If You Don't Review

```
Day 1-3:   Agent knows stuff you don't. You can still follow.
Day 4-7:   Agent references things from 3 days ago. You don't remember.
Day 8-14:  You start trusting the agent blindly. "Just do it."
Day 15-30: You stop understanding what the agent does. You're the passenger.
Month 2+:  The agent is the hacker. You press buttons. You are being automated.
```

## Don't Let This Happen

5 minutes a day. 20 minutes a week. That's the investment. The return is: you become the hacker the agent helps, not the human the agent replaces.
